Quick answers

Before you install.

Does Klavrio send what I type anywhere?

No. Text correction is local. Network access is limited to the official read-only dictionary and application-update feeds; neither request includes your text, and both checks can be disabled.

Can it fix text written before Klavrio was open?

Yes. Select the existing text in another app and press the selected-text shortcut. Klavrio does not need a previous keystroke history.

Is it a spelling or grammar checker?

No. Klavrio repairs keyboard-layout mistakes. It intentionally avoids rewriting uncertain text.

Can I add my own words?

Yes. Personal dictionaries stay local and load last. To share words with everyone, follow the contribution guide and open a pull request for review.

How are Windows updates installed?

Klavrio reads the version and executable URL from its read-only klavrio-update.json. After you approve an available update, it verifies the GitHub asset's size, SHA-256, and embedded version, keeps a rollback copy, replaces the executable, and restarts.
