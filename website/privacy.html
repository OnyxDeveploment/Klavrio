Privacy

Your text belongs to you.

Last updated: 9 October 2026

The short version
  • Keyboard correction runs locally on your device.
  • Klavrio does not require an account or send typed and selected text to a cloud text service.
  • Diagnostics record technical events and errors, not the text you type or select.
  • Network requests occur only for optional update features after you configure their HTTPS URLs.

01 Desktop text processing

Klavrio uses local keyboard maps, dictionaries, reviewed mappings, and confidence rules to recognize keyboard-layout mistakes. Automatic correction examines the bounded word immediately before Space. Selected-text conversion temporarily copies the selection, converts it locally, inserts the result, and attempts to restore the previous clipboard contents.

Klavrio does not use an account, telemetry service, analytics SDK, or cloud translation API for these operations.

02 Diagnostics

Diagnostics can contain timestamps, an anonymous session identifier, application and runtime versions, lifecycle events, operation outcomes, and exception details. Typed words and selected text are not intentionally written to these logs.

Windows logs are stored under %LOCALAPPDATA%\Klavrio\Logs. The macOS edition stores its log under ~/Library/Logs/Klavrio. These files stay on your device unless you choose to share them.

03 Optional network access

Application and community-dictionary update URLs are empty by default. If you configure them, Klavrio can request those HTTPS manifests when it opens or when you ask it to check.

The application-update feature reads version metadata and can open a download or release-notes page in your browser. It does not silently install an application update. The community-data feature can download a dictionary ZIP and validates its HTTPS address, SHA-256 value, size, filenames, and UTF-8 content before activation.

These requests do not include the text you type or select. As with any HTTPS request, the remote host can normally receive technical connection information such as your IP address and user agent.

04 Local settings and dictionaries

Windows settings are stored in %LOCALAPPDATA%\Klavrio\settings.json. Custom and community dictionaries are stored in neighboring Klavrio data folders. On macOS, equivalent data is stored under ~/Library/Application Support/Klavrio.

Your custom dictionary files remain separate from bundled data. Publishing or installing a new application build does not intentionally replace them.

05 Password fields and application limits

Windows password-field detection is best-effort and is reliable only for some native controls. Browsers, terminals, remote desktops, games, elevated applications, and custom editors may block global hooks or injected input or may not expose enough information to identify a sensitive field.

Keep automatic correction disabled in sensitive contexts. You can toggle it with your configured shortcut or from the application tray.

06 This website

This website contains no analytics script, advertising SDK, contact form, or externally hosted font. It stores one optional preference—your light or dark theme—in your browser's local storage.

The company that eventually hosts the site may maintain ordinary server or security logs. Review that provider's policy before publishing if you need hosting-specific disclosures.

07 Removing local data

You can uninstall Klavrio and remove its application-data and log directories to delete its locally stored settings, dictionaries, and diagnostics. Remove its desktop, Start Menu, Startup-folder, or login-item entries if your operating system does not remove them automatically.

Important

This page describes the current repository implementation. Recheck it whenever networking, diagnostics, accounts, hosting, or third-party services change.
