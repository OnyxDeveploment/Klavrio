# Klavrio

**מתקן טקסט שנכתב בפריסת המקלדת הלא נכונה - בלי להקליד מחדש.**

**עברית** · [English](README.md)

---

Klavrio הוא כלי ממוקד פרטיות שעובד מקומית ומתקן טעויות בפריסת המקלדת. הגרסה הראשית מיועדת ל-Windows 10/11, ויש גם גרסה מקורית ל-macOS 13 ומעלה. אפשר לתקן מילים מזוהות אוטומטית בלחיצה על רווח, או לבחור טקסט בתוכנה אחרת ולהמיר אותו בעזרת קיצור דרך גלובלי - גם אם הטקסט נכתב לפני שפתחתם את Klavrio.

> **Windows:** הגרסה הראשית בנויה עם WPF ו-Material Design 3. **macOS:** גרסת SwiftUI נמצאת בתיקייה [macOS/Klavrio](macOS/Klavrio); הוראות הבנייה נמצאות ב-[מדריך של macOS](macOS/Klavrio/README.md). כדי לבנות את גרסת macOS צריך מחשב Mac עם Xcode.

## מה יש בתוכנה

- ממשק Material Design 3 מודרני וגמיש, עם מצב כהה ובהיר, אנימציות עדינות, אייקונים, הסברים קצרים ומגש מערכת ב-Windows
- ממשק ופריסות מקלדת לאנגלית, עברית, ערבית, רוסית, גרמנית וצרפתית
- קיצורי דרך גלובליים שאפשר לשנות: המרת טקסט מסומן והפעלה או כיבוי של התיקון האוטומטי
- מצב חכם לטקסט מעורב ומצבים מפורשים להמרה לכל אחת משש השפות
- קיצורים לשולחן העבודה ולתפריט Start שנוצרים למשתמש הנוכחי בהפעלה הראשונה; Windows יכול להציג את הקיצור החדש תחת **נוספו לאחרונה** כשהאפשרות הזאת מופעלת במערכת
- הפעלה אוטומטית אופציונלית גם דרך תיקיית Startup וגם דרך רשימת Run ברישום, בלי הרשאת מנהל
- כפתור GitHub או אתר פרויקט שאפשר להגדיר
- בדיקות עדכון אופציונליות בזמן ההפעלה, דרך כתובות HTTPS שאפשר להגדיר
- מילונים אישיים בתיקייה נפרדת: **%LOCALAPPDATA%\Klavrio\CustomData**
- הגדרות מקומיות: **%LOCALAPPDATA%\Klavrio\settings.json**
- כל תיקון הטקסט נעשה מקומית - בלי חשבון, טלמטריה או שירות תרגום בענן
- יומנים ברורים להפעלה, הצלחות, אזהרות ושגיאות, כולל דוח נפרד לקריסה
- טקסט שהוקלד או סומן אף פעם לא נכתב ליומן האבחון

## בנייה

ב-Windows, התקינו את ‎.NET 8 SDK והריצו:

```powershell
dotnet build Klavrio.csproj
```

כדי ליצור גרסת x64 עצמאית, הריצו את [Build_Release.bat](Build_Release.bat). הסקריפט כולל את סביבת ‎.NET ואת ספריות WPF הנדרשות, ושומר את קובץ ההפעלה המוכן כאן:

```text
bin\Release\net8.0-windows\Klavrio.exe
```

הגרסה להפצה עדיין כוללת תיקייה קטנה ולא רק קובץ יחיד. התיקיות `Data` ו-`ThirdParty`, הקובץ `LICENSE` והקובץ `THIRD_PARTY_NOTICES.txt` נמצאים ליד קובץ ההפעלה העצמאי. צריך לשמור את כל התיקייה יחד כשמפיצים את Klavrio.

פעולת **Build** רגילה ב-Visual Studio משתמשת גם היא בתיקייה **bin\Release\net8.0-windows**, אבל יוצרת קובץ קטן יותר שתלוי ב-‎.NET ובקובצי DLL נלווים. הפקודה הרגילה **dotnet publish -r win-x64** יוצרת את התיקייה **win-x64\publish**. סקריפט הבנייה של הפרויקט משנה את היעד בכוונה, כדי שקובץ ה-EXE העצמאי והעדכני יהיה תמיד בנתיב הישיר שמופיע למעלה. לפני בנייה, צאו לגמרי מ-Klavrio דרך מגש המערכת כדי ש-Windows לא ינעל את הקובץ.

אפשר לפתוח את [Klavrio.slnx](Klavrio.slnx) ב-Visual Studio או לבנות ישירות את [Klavrio.csproj](Klavrio.csproj).

בזמן הפתיחה Klavrio יוצר או מתקן קיצורים למשתמש הנוכחי בשולחן העבודה ובתפריט Start. התוכנה לא כותבת לשולחן העבודה או לתפריט Start של כל המשתמשים, ולכן אין צורך בהרשאת מנהל. האפשרות **הפעלה עם Windows** מסנכרנת קיצור בתוך **shell:startup** עם ערך Run של המשתמש הנוכחי ברישום. מנגנון ההפעלה היחידה סוגר בשקט את העותק הנוסף ששתי שיטות האתחול עלולות לפתוח.

## שימוש

### תיקון טקסט מסומן

1. סמנו טקסט ב-Notepad או בתוכנת שולחן עבודה אחרת שתומכת בהעתקה והדבקה רגילות.
2. לחצו על קיצור הדרך שהוגדר להמרת טקסט. ברירת המחדל היא **Ctrl + Shift + Space**.
3. Klavrio מעתיק זמנית את הטקסט המסומן, ממיר אותו, מקליד את התוצאה ומנסה להחזיר את תוכן הלוח הקודם.

מצבי ההמרה:

- **חכם ואוטומטי · טקסט מעורב** משאיר מילים תקינות כמו שהן, ומתקן רק התאמה חד-משמעית שמבוססת על מילון או על מיפוי שנבדק ידנית.
- מצבי **המרה אל…** ממירים את מיקום המקשים הפיזי לאנגלית, עברית, ערבית, רוסית, גרמנית או צרפתית.

השיטה הזאת מתקנת גם טקסט שנכתב לפני ש-Klavrio נפתח: פתחו את התוכנה, סמנו את הטקסט הקיים ולחצו על קיצור הדרך. Klavrio לא צריך להקליט הקשות קודמות.

כדי לשנות קיצור דרך, לחצו על כפתור הקיצור המתאים בתוך התוכנה ואז לחצו על הצירוף החדש. אפשר להשתמש במקשים F1–F24 לבד; מקשים אחרים דורשים Ctrl, Alt או Shift. אם קיצור הדרך כבר תפוס בידי תוכנה אחרת, Windows ידחה אותו ו-Klavrio ישמור את הקיצור הקודם שעבד.

הכפתור **שחזור ברירות מחדל** בהגדרות מאפס את שפת הממשק, ערכת הנושא, הפעלה עם המחשב, תיקון אוטומטי, מצב ההמרה, קיצורי הדרך, כתובת הפרויקט והתנהגות הסגירה למגש. לפני האיפוס תופיע בקשת אישור.

### תיקון אוטומטי

הפעילו את **תיקון אוטומטי** כדי לבדוק את המילה שלפני הרווח. Klavrio משנה טקסט רק כשנמצאה התאמה מדויקת במילון. קיצור הדרך להפעלה ולכיבוי הוא **Ctrl + Alt + Space** כברירת מחדל.

האפשרות כבויה בהפעלה הראשונה, והבחירה שלכם נשמרת.

## פרטיות ובטיחות

Klavrio לא שולח ולא שומר ביומן מילים שהוקלדו או טקסט שסומן. אם הוגדרו בדיקות עדכון, התוכנה מבקשת רק את קובצי ה-HTTPS שהוגדרו ואת חבילת המילונים. יומן האבחון מכיל זמנים, מזהה הפעלה אקראי, אירועי הפעלה, תוצאות פעולות, גרסאות תוכנה ופרטי חריגות.

היומן משתמש בזמנים מקומיים קצרים, רמות חומרה מסודרות ושדות קריאים. כל הפעלה מתחילה בכותרת ברורה, ו-stack trace מופיע בשורות נפרדות. הקובץ נמצא כאן:

```text
%LOCALAPPDATA%\Klavrio\Logs\klavrio.log
```

היומן הראשי מתחלף כשהוא מגיע ל-2 MB. בשדרוג מפורמט היומן הישן, Klavrio שומר אותו בשם **klavrio-legacy-*.log** ומתחיל יומן חדש וקריא. שגיאה חמורה יוצרת גם קובץ **crash-*.log** עם תאריך ושעה; דוחות קריסה בני יותר מ-30 יום נמחקים בזמן ההפעלה.

זיהוי שדות סיסמה הוא ניסיון הגנה נוסף, אבל הוא עובד בצורה אמינה רק בחלק מהפקדים הרגילים של Windows. דפדפנים, מסופים, תוכנות עם הרשאת מנהל, משחקים, שולחן עבודה מרוחק ועורכים מותאמים עלולים לחסום hook גלובלי או קלט מדומה. מומלץ להשאיר את התיקון האוטומטי כבוי בשדות רגישים, לבדוק קודם ב-Notepad ולהשתמש ב-**Ctrl+Z** אם התקבלה תוצאה לא צפויה.

Klavrio כולל קובץ מילון אחד, מאוחד וללא כפילויות, לכל שפה. חבילת 100K באנגלית ובעברית והחלק השימושי בעברית מחבילת השמות הרב־לשונית מוזגו לקבצים האלה. רשימות שמות כלליות בשפות לא קשורות לא הוכנסו, כדי לא לפגוע באיכות הזיהוי. זוגות עברית מדויקים ומיפויים פונטיים נשארו בקובצי TSV נפרדים ומקבלים עדיפות. לדוגמה: **nv t,v eurt** הופך ל-**מה אתה קורא**, ו-**VHH ma kore** הופך ל-**היי מה קורה**.

להוספה ידנית, פתחו **הגדרות ← מילונים אישיים ← פתיחת תיקיית הנתונים האישיים**. הקבצים נמצאים תחת **%LOCALAPPDATA%\Klavrio\CustomData**, לא נדרסים בעת פרסום גרסה חדשה, ונטענים אחרי שאר המילונים כך שהם יכולים לעקוף מיפויים קיימים. הוסיפו מילה אחת בכל שורה או השתמשו בדוגמאות ה-TSV, שמרו ולחצו על **טעינת מילונים מחדש**. אין צורך להפעיל מחדש את התוכנה.

## עדכוני מילונים מהקהילה

המילונים בצרפתית, גרמנית, ערבית ורוסית מאוחדים עם הרשימות של LibreOffice ו-Hunspell ומנוקים מכפילויות. גרסת המקור, הקרדיטים והרישיונות רשומים ב-[Data/COMMUNITY_DICTIONARY_LICENSES.txt](Data/COMMUNITY_DICTIONARY_LICENSES.txt). כלי הייבוא והאיחוד נמצאים ב-**tools/Import-LibreOfficeDictionaries.ps1** וב-**tools/Merge-BundledDictionaryData.ps1**.

אפשר להוסיף מילים דרך Pull Request ב-GitHub. תהליך ה-GitHub Actions בודק UTF-8, כפילויות, קיום מילונים נדרשים ומבנה TSV בכל בקשה. אחרי שמאשרים וממזגים שינוי אל **main**, התהליך יוצר אוטומטית חבילת מילונים עם גרסה ומעדכן manifest קבוע. את הכתובת הבאה מגדירים תחת **הגדרות ← עדכוני מילים מהקהילה**:

```text
https://github.com/OWNER/REPOSITORY/releases/download/dictionary-feed/dictionary-manifest.json
```

Klavrio בודק את כתובת ה-HTTPS, גיבוב SHA-256, גודל החבילה לאחר חילוץ, שמות קבצים ותוכן UTF-8 לפני התקנה אטומית תחת `%LOCALAPPDATA%\Klavrio\CommunityData`. קבצים אישיים ב-`CustomData` עדיין נטענים אחרונים. בדיקה או הורדה שנכשלו אף פעם לא מחליפות את החבילה המקומית האחרונה שעבדה.

פרטים על תרומה ותחזוקת המאגר נמצאים ב-[CONTRIBUTING.md](CONTRIBUTING.md), כולל הגדרות ההגנה והאישור הנדרשות לענף הראשי.

## בדיקת עדכוני תוכנה

בדיקת העדכונים מופעלת כברירת מחדל, אבל לא מתבצעת בקשת רשת עד שמגדירים כתובת HTTPS בהגדרות. הבדיקה קוראת מידע על הגרסה בלבד; Klavrio לא מוריד ולא מתקין עדכון לתוכנה באופן אוטומטי. כשיש גרסה חדשה, Klavrio יכול לפתוח בדפדפן את כתובת ההורדה או את דף פרטי הגרסה. מבנה ה-JSON הצפוי:

```json
{
  "version": "1.1.0",
  "downloadUrl": "https://example.com/Klavrio.exe",
  "releaseNotesUrl": "https://example.com/releases/1.1.0"
}
```

גודל התגובה מוגבל ל-64 KB והבקשה נעצרת אחרי שמונה שניות. גם כתובת ההורדה וכתובת פרטי הגרסה חייבות להשתמש ב-HTTPS.

## מגבלות ידועות

- Klavrio מתקן טעויות בפריסת מקלדת; הוא לא בודק איות או דקדוק.
- המצב החכם משתמש בכללים והערכות, ולא בהבנה מלאה של שפה טבעית.
- לא תמיד אפשר לשמור בצורה מושלמת פורמטים עשירים או תוכן לוח שמגיע באיחור.
- **SendInput** לא יכול לכתוב לתוכנה שרצה בהרשאה גבוהה יותר מ-Klavrio.
- התיקון האוטומטי בודק מילים בודדות ולא הקשר של משפט שלם. כשאין התאמה במילון, אפשר להשתמש בהמרה מפורשת של טקסט מסומן.

## תודות

Klavrio מתאפשר בזכות האנשים והפרויקטים שהעבודה שלהם משמשת בו:

- תודה מיוחדת ל-**Kevin Atkinson ולתורמי SCOWL**, ל-**Alan Beale**, ולכל יוצרי ומתחזקי רשימות המילים שמופיעים ב-[Data/THIRD_PARTY_LICENSE.txt](Data/THIRD_PARTY_LICENSE.txt). העבודה שלהם היא הבסיס לנתוני המילון באנגלית.
- תודה ל-**מתחזקי המילונים של LibreOffice ו-Hunspell** ולתורמי המילונים בערבית, גרמנית, צרפתית ורוסית שמופיעים ב-[Data/COMMUNITY_DICTIONARY_LICENSES.txt](Data/COMMUNITY_DICTIONARY_LICENSES.txt).
- הממשק של Windows משתמש ב-**Material Design In XAML Toolkit** מאת James Willock, ‏Mulholland Software והתורמים לפרויקט, ובאייקונים של **Material Design Icons** מבית Pictogrammers.
